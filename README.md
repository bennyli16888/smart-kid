# 萌学园 v0.2.1

网页：<https://bennyli16888.github.io/smart-kid/>

面向幼儿的原创萌宠启蒙课堂，无账号、广告或计时。10 个动物伙伴各有自己的全站配色和课堂主题，选科目、难度和 10 / 20 / 30 的学习量即可开始，不再按年龄划分，也不再分多种教学模式。

| 科目 | 简单 | 进阶 | 挑战 |
| --- | --- | --- | --- |
| 语文 | 基础汉字及拼音 | 常见词语 | 生活短语 |
| 数学 | 10以内加减法 | 20以内加减法 | 30以内加减法 |
| 英语 | 身边物品 | 家与自然 | 日常生活 |

语文、英语每个难度各有 10 个字词；20 / 30 次学习通过打乱顺序重复巩固。英语配有原创 SVG 图片。数学随机生成指定数量的不重复题目，数值和结果均不超出所选范围，没有负数。

每道数学题都可打开“用星星讲给我听”：先摆好 → 拿来或拿走 → 数剩余星星。星星可点击报数，拿走的星星打叉，不使用孩子看不懂的公式推导。答错可以重试，答对或完成字词学习获得一颗星星；进度仅存在当前浏览器。

## 声音

首次打开不会自动播放（浏览器限制），请点 **“开启 / 试听声音”**；也可以直接点课堂里的 **“听一听”**。字词、英文单词、数字和讲解使用随网站提供的 107 个 MP3，不需要设备安装中英文语音库，也不在使用时请求外部朗读服务。全站开关可以关闭自动跟读；明确点击“听一听”会重新开启。

如果听不到，查看按钮下的提示，检查设备媒体音量、静音模式和网络。音频文件加载失败时，单词会尝试设备语音作为备用。仍不可用会明确提示，不会把失败显示为“已播放”。

朗读会在浏览器中去掉音频首尾的长留白，缓存当前和下一题的读音，再将数学问题及单个讲解步骤拼成一段连续音频，避免逐词等待加载。保留短接缝和发音安全边距；不支持解码的浏览器会退回原 MP3。

声音栏可选择 **原声 / 活泼 / 软萌**，切换时自动试听并保存偏好。活泼和软萌是对现有配音适度调速、调高音调，不是不同配音演员或真实儿童声音。不同浏览器对音高变化的支持可能不同。

MP3 由公开教学字词生成，离线文件放在 `audio/`；可选重生成命令为 `node test/generate-audio.js`，该脚本会将公开字词提交给 Google Translate 的读音端点，需要联网和 curl。网页本身不依赖此端点。

## 本地运行和部署

```bash
python3 -m http.server 8000
```

打开 <http://localhost:8000/>。手机和电脑在同一局域网时，手机也可访问 `http://电脑局域网地址:8000/`（需允许防火墙访问）。本地直接双击 HTML 时，浏览器可能限制音频加载，推荐使用本地服务。

GitHub Pages 使用 `main` 分支根目录；必须一并上传 `index.html`、`css/`、`js/` 和 `audio/`。所有资源为相对路径，支持仓库子路径。

## 验证

```bash
node test/content.js
node test/audio.js
node test/smoke.js
```

后者需要 Node.js 22 和 `chromium-browser`，无 npm 依赖。检查实际 MP3 播放、播放拦截提示、角色主题、三科目 × 三难度 × 三题量、解法和手机/电脑布局。自动化无法确认用户设备扬声器的实际音量。

UI 的方格纸、粗描边和贴纸按钮借鉴 Bunny Math 的设计方向；未复制其角色或代码，图案和界面在本项目独立制作。
