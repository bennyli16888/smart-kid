# 萌学园 v0.7

网页：<https://bennyli16888.github.io/smart-kid/>

面向幼儿的原创萌宠启蒙课堂，无账号、广告或计时。10 个动物伙伴各有自己的全站配色和课堂主题，提供语文、数学、英语。学习选项、答案、奖励标记和物品选择使用协调的柔和彩色，保留浅色底和深色文字。

| 科目 | 简单 | 进阶 | 挑战 |
| --- | --- | --- | --- |
| 语文 | 基础汉字及拼音 | 常见词语 | 生活短语 |
| 数学 | 10以内加减法 | 20以内加减法 | 自定义1—100以内 |
| 英语 | 身边物品 | 家与自然 | 日常生活 |

语文、英语每科各 90 个字词，每个难度 30 个，配有 SVG 或系统 Emoji 图片。开始前可选两种方式：“看和听”展示图片、字词与读音；“听后找一找”播放读音后从 3 张图片中选择，第一次答错会显示拼音或译义提示并重播，第二次答错会展示答案，答对后才能继续。题量提供 10、20、自定义（1—100）。默认不重复；勾选“可重复巩固”后展开 10% / 20% / 30% 比例。例如 20 次、30% 重复，包含 14 个不同字词及 6 次额外重复。重复次数四舍五入；不同字词需求超过材料数量时会提示调整，不会暗中重复或减少数量。

数学随机生成指定数量的不重复题目，数字和结果均不超出所选范围，没有负数。20 以内的题目会用物品辅助作答：加法分成两组点击数数，减法先点出要拿走的物品、再数剩余物品，完成后才可选择结果；更大的自定义范围保留直接选择，避免出现过多物品。范围太小无法提供足量不同题目时会明确提示。讲解默认使用五彩糖果；进入题目后，点“讲给我听”右侧的 **“换讲解物品”** 才展开选择，也可换成香蕉、苹果、橙子、草莓、葡萄、梨、桃子或西瓜，共9种。选好后自动收起，同一题的讲解文字、画面和朗读同步更新，不重置答题进度。分步讲解为：先摆好 → 拿来或拿走 → 数剩余实物。答错可以重试，答对或完成字词学习获得一颗星星；进度仅存在当前浏览器。

## 声音

首次打开不会自动播放（浏览器限制）。声音开启时，按钮会播放由浏览器 Web Audio 即时合成的轻柔双音提示。右上角可在小宇、小悠、小夏间切换；选中后会立即播放该音色的问候语试听，选择会保存在当前浏览器。试听不会改变声音开关状态。每种音色都使用自己的305条完整语音，不会混播其他音色。声音开启时先朗读当前题，再于浏览器空闲时预载讲解音轨，待其就绪后预载下一题；静音时不预加载课程音频。解码录音缓存最多保留120条，首次下载与解码仍可能因网络或设备速度稍有等待。音轨清单和文件路径见 `audio/voices/manifest.json`。

## 本地运行和部署

```bash
python3 -m http.server 8000
```

打开 <http://localhost:8000/>。手机和电脑在同一局域网时，手机也可访问 `http://电脑局域网地址:8000/`（需允许防火墙访问）。本地直接双击 HTML 时，浏览器可能限制音频加载，推荐使用本地服务。

GitHub Pages 通过 `.github/workflows/pages.yml` 从 `main` 部署；仓库 Pages Source 需设为 **GitHub Actions**。工作流只发布 `index.html`、`css/`、`js/` 和 `audio/voices/`，并设置较长部署等待时间以容纳语音文件。所有资源为相对路径，支持仓库子路径。

## 验证

```bash
node test/content.js
node test/audio.js
node test/smoke.js
```

后者需要 Node.js 22 和 `chromium-browser`，无 npm 依赖。检查实际朗读、播放拦截提示、角色主题、默认不重复、重复比例、自定义数量/数字范围、课堂内折叠物品选择及同步讲解，以及手机/电脑布局。内容测试还验证逐文件生成记录与校验值。自动化无法确认用户设备扬声器的实际音量或主观音色质量。

UI 的方格纸、粗描边和贴纸按钮借鉴 Bunny Math 的设计方向；未复制其角色或代码，图案和界面在本项目独立制作。
