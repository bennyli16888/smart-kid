# 萌学园 v0.1

面向 3–6 岁孩子的语文、数学、英语启蒙网页应用。按年龄和科目选择内容，包含翻卡片、动画课、日常用语和找一找小游戏；孩子可选择 10 个原创 SVG 动物伙伴，答题获得星星。无需账号、后端或构建工具，进度只保存在当前浏览器。

## 本地使用

在项目目录运行：

```bash
python3 -m http.server 8000
```

用浏览器打开 <http://localhost:8000/>。手机与电脑处于同一局域网时，也可在手机访问 `http://电脑局域网地址:8000/`（需允许防火墙访问）。

## 部署到 GitHub Pages

1. 将本目录的 `index.html`、`css/`、`js/` 上传到 GitHub 仓库根目录。
2. 进入仓库 **Settings → Pages**，将 **Build and deployment** 的 **Source** 设为 **Deploy from a branch**；选择主分支和 **/(root)** 并保存。
3. 等待部署完成，打开页面给出的链接（通常是 `https://用户名.github.io/仓库名/`）。

资源均使用相对路径，支持仓库子路径，无需修改配置。

## 提示

语音使用浏览器内置的 Web Speech API，首次点击后通常才能播放；如果浏览器没有安装对应的中文或英文语音，发音可能不可用或口音因设备而异。需要声音时，请检查设备音量和首页右上的 🔊 开关。页面不依赖网络接口，可离线使用已下载的文件。
